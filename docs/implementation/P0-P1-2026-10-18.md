## 本轮实际增量

1. `scripts/dev-wsl.mjs` 提供本地初始化、启动和数据库停止入口。PostgreSQL 使用已存在的精确 digest 镜像，在回环随机端口运行，512 MiB/2 CPU 限额，开发数据保存在 `.local-dev/postgres`。密钥及随机初始账号仅在 `.local-dev/`，权限 0600，Git 忽略。没有生产账号或默认密码，没有自动连接目标。
2. `scripts/test-native-postgres.mjs` 启动独立临时原生 PostgreSQL，执行 Go race 测试并清理自己创建的容器。必做测试未执行、跳过、失败或输出解析失败均不能通过。保存时间、版本、文件摘要、原始结果与退出码。
3. 原资产编辑要求手写 JSON，现提供同设计系统的结构化表单，含独立 SSH/SFTP/RDP 开关、地址、端口、网关、标签和虚拟化元数据。未启用协议的字段真正禁用。保存只登记资产，不表示目标在线。
4. 资产更新加入版本条件写入：旧版本返回 409，缺版本返回 400，客户端保留输入并要求刷新核对。既有调用方 PATCH 需补传 version，契约已更新。
5. 需求检查入口核对 187 个 ID、状态、证据路径和 MUST 分母；此检查只证明追踪结构，不证明产品完成。
