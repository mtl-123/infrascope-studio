## 2 关键冲突与裁决

| 表面冲突 | 采用行为 | 为什么以及如何验证 |
|---|---|---|
| “后端 Rust”与现有 Go 远程实现 | Go 管理/现有网关继续复用，Rust 新增采集和遥测数据面 | 不重复身份或协议网关；ADR 和统一 ID/权限测试证明整合 |
| “Web Go”与现有 JS 页面 | Go 提供服务/BFF，浏览器沿用现有前端 | 语言职责不同；在现有主题中完成真实流程 |
| 原型没有用户/SSH/SFTP 与新增必做 | 按第0节实现新增能力并保留 RDP 基线 | 不把旧状态当禁令 |
| 原型无依赖/单页 与宿主已有框架 | 本机连接器基线独立遵守，平台依赖按宿主和维护库 | 不删除宿主锁文件；保留版本与许可证 |
| 原型 0.0.0.0/宽松布尔/任意目标 与多人安全 | 回环监听、严格 schema、Host/Origin、任务授权和端点注册 | 记录旧行为→新行为→兼容影响；负例证明没有自由入口后门 |
| 原型独立视觉 与当前项目主题 | 平台使用宿主视觉；保留本机页才复现其像素/DOM/文案 | 状态/字段不丢；320/520/780px 和桌面实测 |
| 旧凭据覆盖/删除 与多账号并发 | 既有凭据拒绝覆盖或采用可验证安全方案；目标锁与所有权清理 | 同地址不同端口仍同 TERMSRV，不能假装天然隔离 |
| 原型密码字符上限 与 Windows 原生字节上限 | 严格校验两者，以实际系统允许的更小上限拒绝并友好提示 | 真实 Win API 长度边界，不能把可提交字符串当可写入凭据 |
| “很精准实时” 与采样和不同计数层 | 报实际间隔的区间速率、口径/质量/误差及历史 | 独立同层参考，不承诺绝对零误差或毫秒即时 |
| “在线天数/关机” 与仅有心跳 | 系统 uptime、连续探测、最后见到、关机证据分别显示 | 断网测试不得伪装为确认关机 |
| Docker “按名称” 与名称可重复/重建 | 名称组带环境/业务/项目作用域并有稳定 ID，实例下钻 | 跨环境同名和重建用例验证 |
| 附件不要求虚拟化管理 API 与早期 PVE 监控 | 监控模块接只读 PVE 数据；远程模块仍访问来宾端点 | 不扩为创建/关机/快照/宿主磁盘管理 |
| 日志可靠 与 UDP/源日志已清除 | 支持接入并记录能力/缺口，不能承诺不可观测的总产生数 | UDP/轮转/覆盖试验和质量状态 |
| “所有测试正常” 与当前环境缺失 | 实现不能延期，实机验收被阻塞则明确整体未完成 | 建环境/给具体条件；不伪造通过或删掉分母 |
| AI 调查与自动执行 | 真实证据、模型配置和受限诊断；写操作单独授权 | 注入/越权/无证据用例，不把模型建议直接当命令 |
| 企业微信 @ 和手工联系人 | 使用真实成员ID/支持的消息类型，自定义联系人走实际配置渠道 | 不用文本 @姓名 代替 API 支持的提醒 |

## 4 不丢细节的执行规则

- 主 PRD 的 REQ 用于功能与阶段组织；source 文件用于原型和协议细节，两者一起构成需求。
- 逐条核对清单包含原附件的说明、示例、可选项和硬性要求，不能把全部示例当成生产常量，也不能把“旧现状”当成最终限制。
- 表格、代码块和正文中的具体设置，如 18 项 RDP 配置、全部 DOM 标识、默认值、超时、策略指纹和 API 错误，也必须落入实际测试，不得仅做存在性检查。
- 清单映射到 REQ/E2E 只表示已确定阅读和验证入口，未填实际测试与证据仍然是 NOT_REVIEWED/NOT_RUN。
- 发现更细的独立要求时新增子 ID，保留原 ID 关系；不得覆盖原记录导致历史验收失联。
- 完成阶段报告时同时核对 REQ、来源 H、附件细则三个维度。机械“都有编号”不等于语义完整，更不等于软件通过。
